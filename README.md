# Laboratorio Zabbix · Guía del aprendiz

Guía didáctica para la actividad 1 del punto 3.3 de monitoreo, ficha 3399813.

Incluye las 49 secciones, 57 bloques de comandos explicados, diagramas, glosario, comprobaciones, simulador de tráfico, seguimiento local, guía Word y hoja de registro descargables.

Esta publicación es autocontenida: **index.html incluye todos los estilos, programas, ilustraciones y documentos descargables**. No requiere carpetas de recursos, dependencias, compilación ni servicios adicionales. Puede abrirse también como archivo local.

El avance se guarda solo en el navegador. Los gráficos del simulador son didácticos; las evidencias del laboratorio se obtienen en los equipos reales.

Para GitHub Pages: rama main, carpeta /(root). El archivo .nojekyll permite servir la web estática directamente.
